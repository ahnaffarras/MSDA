# MSDA Dashboard

A Next.js dashboard for the MikroTik Smart DNS Analytics (MSDA) project.

## Stack
- Next.js 16 with the App Router
- Tailwind CSS
- Hero UI
- Gravity UI Icons
- Geist font

## Run locally

```bash
cd services/dashboard
npm run dev
```

Open http://localhost:3000 to view the dashboard.

## Build verification

```bash
npm run build
```
