SCENARIO 1: Tambah lab baru
  Problem: Ada lab baru "Lab Bahasa" dengan AP IP 192.168.50.1
  Solution:
    1. Buka /settings
    2. Klik "Tambah Lab"
    3. Nama: "Lab Bahasa", IP: "192.168.50.1"
    4. Map IP dari logs ke lab ini
  Result: Lab baru muncul di dashboard dengan nama "Lab Bahasa"

SCENARIO 2: Rename lab existing
  Problem: "Lab Komputer 1" mau diganti jadi "Lab Desain Grafis"
  Solution:
    1. Buka /settings > Tab "Kelola Lab"
    2. Cari "Lab Komputer 1"
    3. Klik "Edit"
    4. Ubah nama jadi "Lab Desain Grafis"
  Result: Tab di dashboard otomatis berubah nama

SCENARIO 3: IP baru terdeteksi
  Problem: IP 192.168.10.50 muncul di logs, mau dimasukkan ke Lab 1
  Solution:
    1. Buka /settings > Tab "Mapping IP"
    2. Pilih "Lab Komputer 1" dari dropdown
    3. Cari IP 192.168.10.50 di list "IP yang Tersedia"
    4. Klik "Map ke Lab"
  Result: IP 192.168.10.50 sekarang jadi PC-37 di Lab 1

SCENARIO 4: Hapus lab yang tidak digunakan
  Problem: Lab 3 sudah tidak dipakai
  Solution:
    1. Buka /settings > Tab "Kelola Lab"
    2. Cari "Lab Komputer 3"
    3. Klik "Hapus"
    4. Konfirmasi penghapusan
  Result: Lab 3 hilang dari dashboard dan semua mapping IP dihapus

Lab tidak muncul?

  → Cek apakah ada IP yang sudah dimapping
  → Refresh halaman

IP tidak muncul di "Available"?
  → Pastikan IP ada di dns_events
  → Cek timestamp (hanya 24 jam terakhir)
  → IP mungkin sudah dimapping ke lab lain

Error saat seed?
  → Jalankan: mongosh msda --eval "db.lab_configs.drop();"
  → Jalankan ulang: npm run seed:labs

Mobile menu tidak muncul?
  → Clear browser cache
  → Coba di incognito mode
  → Pastikan JavaScript enabled
